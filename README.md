# Car Price Prediction

A Machine Learning project that predicts used car prices using car-related features.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit

## Model
Random Forest Regressor

## Model Performance
- R² Score: 0.907
- MAE: 883.27
- RMSE: 1218.90

## How to Run
1. Install the required Python libraries.
2. Make sure the trained model and encoder files are available.
3. Run the Streamlit application.

```bash
streamlit run app.py
```

## Project Purpose
This project demonstrates data preprocessing, categorical encoding, model training, evaluation, and deployment using Streamlit.
